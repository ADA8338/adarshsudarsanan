# 🐍 Snake Game

A classic **Snake Game** built using Python. The game features different game modes, AI enhancements, and smooth gameplay mechanics.

## 🎮 Features
- **Smarter AI movement** using state representation or CNN.
- **Dynamic speed adjustments** based on snake length.
- **Better collision handling**, including wall wrapping and obstacles.
- **Multiple game modes** (Classic, Survival, Maze).
- **Power-ups** (Speed Boost, Slow Motion, Reverse Controls).
- **Multiplayer support** (Human vs AI, Local Multiplayer).
- **Leaderboard & score system** with database/file storage.
- **Graphical enhancements** (animations, UI improvements, particle effects).
